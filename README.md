# BMI Calculator Dashboard

A responsive BMI Calculator web application built with
Python Flask, HTML, CSS, and JavaScript.

## Features
- Calculate BMI using height and weight
- Display BMI category and health advice
- Interactive dashboard and BMI gauge
- Recent calculation history during the browser session
- Input validation

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript

## How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Install dependencies:

   pip install -r requirements.txt

4. Start the application:

   python app.py

5. Open http://127.0.0.1:5000 in your browser.

## Disclaimer
BMI is a screening tool and is not a medical diagnosis.
